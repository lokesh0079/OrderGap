
# OrderGap

OrderGap is a React-based order management application designed for small clothing businesses.

## Problem

Clothing businesses often receive customer orders through WhatsApp and other messaging platforms. Manually transferring these conversations into structured orders can lead to missing information and mistakes.

## Solution

OrderGap helps business owners convert customer conversations into structured order information, identify missing details, and review extracted information.

## Current Features

- Dashboard with order statistics
- Customer information form
- Manual customer conversation input
- Product extraction
- Quantity extraction
- Size and color extraction
- Price extraction
- Delivery date extraction
- Delivery address extraction
- Missing information detection

## Tech Stack

- React
- JavaScript
- Vite
- React Router
- Redux Toolkit
- Bootstrap
- React Icons

## Getting Started

Clone the repository:

```bash
git clone https://github.com/YOUR_USERNAME/OrderGap.git
```

Install dependencies:

```bash
npm install
```

Start development server:

```bash
npm run dev
```
